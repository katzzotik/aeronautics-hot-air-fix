# What does this mod do?
This mod fixes an issue that appears when using Create: Aeronautics with Iris Shaders.
When a hot air envelope is filled with air, a transparent overlay appears. This overlay absolutely does not work well with shaders, and creates a weird artifact in the top left corner that becomes larger as more  hot air overlays are present. The transparent overlay also looks weird.

[![Before](https://cdn.modrinth.com/data/Qhi65c7K/images/fdb0cbe2dd78eff9a455148c3077ebcfb95e6b32.jpeg)](https://cdn.modrinth.com/data/Qhi65c7K/images/fdb0cbe2dd78eff9a455148c3077ebcfb95e6b32.jpeg)

# How does this mod fix it?
This mod simply disables this overlay using an embedded resource pack.\
As result, the hot air overlay is completely gone, solving the issue.

[![After](https://cdn.modrinth.com/data/Qhi65c7K/images/e4c75aaca7a5bc6308af72bd9f25b797c8c22a6f.jpeg)](https://cdn.modrinth.com/data/Qhi65c7K/images/e4c75aaca7a5bc6308af72bd9f25b797c8c22a6f.jpeg)

This mod is available as Neoforge mod and normal resource pack.\
